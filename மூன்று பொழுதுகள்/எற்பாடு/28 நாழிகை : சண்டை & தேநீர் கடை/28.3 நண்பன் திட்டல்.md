# நண்பன் திட்டல்

தன் ஆசை மகளை   
கண்களில் நீர் ததும்ப    
கட்டியணைத்து 
முத்தமிட 

கண்ட காட்சியில் இதயம் இலகுவாக    
புன்னகையோடு   
பின்னால் திரும்பினேன்    
முறைத்தபடி நின்றிருந்தான்    
நண்பன்  

கண்களை சிமிட்டியபடி    
அவன் தோள்களை தட்டி   
கூறினேன் 
'வா தேநீர் வாங்கி தரேன் '
சரியென பலகாரமும் 
வாங்கி தரும் 
ஒப்பந்தத்தோடு 
வண்டியில் ஏறினான்  

அவர் நன்றி சொல்லும் முகமூடியை    
தேடி எடுக்கும் முன்
