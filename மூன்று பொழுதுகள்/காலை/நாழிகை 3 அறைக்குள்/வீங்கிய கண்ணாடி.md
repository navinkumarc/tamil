# வீங்கிய கண்ணாடி

கண்ணாடி முன் நின்று    
கைகளை மடக்கி கழுத்தை முறுக்கி    
எதிர்பார்த்த பலன் இன்றி    
ஏமாற்றமே என்றும் போல்    
கைகளில் இல்லாமல் வயிற்றில் தெரிந்தது    
சிறு வீக்கம்    
ஓடியாடி விளையாடாமல்    
ஒளித்திரையில் உட்கார்ந்து     
விளையாடியதன் பலன்    

குளித்த பின் மேலும் மணக்க     
வாசனை திரவியம் அடிக்க    
அறை முழுதும்     
நறுமணம் நிறைந்தது    

அனுமதியின்றி நுழைந்து    
திட்டி தீர்க்கும்    
அம்மாவிற்கு மட்டும்     
தலைவலி தந்தது     
அறைக்குள் நுழைந்ததும்
